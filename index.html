Fórmulas (95%, z = 1,96)

Poker: EE = sd/√(manos/100); IC = wr ± z·EE; manos necesarias para que el límite inferior sea > 0 = 100·(z·sd/wr)².
Trading media: EE = σ/√n; IC = μ ± z·EE; n necesario = (z·σ/μ)².
Sharpe por periodo S = μ/σ; EE(S) ≈ √((1+S²/2)/n) (Lo, 2002, datos iid); n necesario = z²(1+S²/2)/S²; anualizado = S·√(periodos/año).
